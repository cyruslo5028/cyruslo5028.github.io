The game auto-loads them. If a file is missing, the SVG silhouette
fallback renders instead.

## Recommended specs

- **Format**: PNG with transparent background (best), 512×680 or larger
- **Aspect ratio**: roughly 3:4 (cards crop to 3:4)
- **Composition**: full-body or chest-up, character centered, looking forward
  or 3/4 view, dark background OK if not transparent
- **Style**: HK 90s gangster manhua / anime, neon-noir colors

## Quick way to bulk-generate (Bing Image Creator, free)

1. Go to <https://www.bing.com/images/create>
2. Paste each prompt above
3. Generate, download the image you like
4. Rename to the exact filename shown above
5. Drop into this folder
6. Refresh the dev server - portraits auto-load
